What's actually different

01 — Color roles

Flat grey → tonal ember

The current screen tints icons and links a single flat blue. The Expressive version pulls a warm ember accent through icon containers, category labels, and the Ultra row, with a separate violet role reserved for that one Ultra-tier row.

02 — Shape

Square rows → contained rows

Rows go from edge-to-edge dividers to individually rounded, inset containers — each row reads as its own tappable object instead of one continuous list.

03 — Icon treatment

Bare glyph → tonal container

Icons move from plain grey strokes into small rounded-square containers tinted from the same palette — the M3 Expressive "icon container" pattern.

04 — Type

Roboto default → Lexend, set deliberately

Titles pick up more weight and a rounder letterform; the search field and app bar both commit to the same face instead of inheriting the system default.

What this mockup can't show: Expressive's spring-based motion and new component shapes (morphing toolbars, expressive FAB menus) come from Material Components library code this app wasn't compiled against — a patch can restyle colors, shape, and type like above, but can't add component behavior the library never shipped.
